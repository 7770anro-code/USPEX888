# VideoBot

Отдельный Telegram-бот: **идея / пресет / свой текст → вертикальный ролик 30–60 секунд (TikTok 9:16)**.

Не связан с USPEX/Vector. На сервере: `/opt/videobot`, unit `videobot.service`.

## Пайплайн

1. **Grok** (`grok-4.5`, fallback fast) — JSON: `continuity` + 4–6 сцен. Пресет добавляет хук, темп и CTA в бриф.
2. **ElevenLabs** — TTS, сырой `audio/mpeg`. 21 голос кнопками. Подача и скорость — `voice_settings` (stability / similarity_boost / style / speed), в чате только понятные названия.
3. **Runway** `https://api.dev.runwayml.com`, `X-Runway-Version: 2024-11-06`.
   - Вертикаль `720:1280`. Клип 5 или 10 сек.
   - Качество в UI: **Быстро** (`gen4_turbo` I2V) / **Оптимально** (`gen4.5`). Названия моделей пользователю не показываем.
   - Камера и движение — фрагменты `promptText`, не отдельные API-поля.
   - Одно исходное фото на все клипы. `contentModeration.publicFigureThreshold=auto`. SAFETY на картинке → текст про реальных людей.
4. **ffmpeg** — `atempo`, склейка 9:16, burn-in субтитры плашкой на всю сцену (не пословный тайминг).
5. Перед запуском — оценка кредитов Runway + символы ElevenLabs, кнопки Создать / Изменить / Отмена.
6. Статус: процент от весов этапов (сценарий / кадр / озвучка / видео N из M / монтаж), не выдуманный прогресс.

## Режимы

- **Видео за 1 клик** — одна идея, затем настройки и подтверждение стоимости.
- **Своё фото + текст + голос** — готовый сценарий, фото, согласие, голос, настройки, стоимость.
- **Пресеты** — Вирусный TikTok / Реклама товара / Мем / Личный бренд / Кино-история. Пользователь пишет только тему.
- Фото человека: пайплайн **не стартует** без `consent_verified`. То же правило — хард-константа для будущего клонирования голоса, video-to-video и «оживить персонажа».

Ошибки API — текстом в чат. Деплой: [DEPLOY.md](DEPLOY.md).

## Roadmap / Backlog (Волна 2 — не реализуем сейчас)

Нужна БД, отдельный этап. Не начинать в этом PR:

- Instant Voice Cloning (голос пользователя: согласие кнопкой, удаление, журнал)
- Voice Design (голос по текстовому описанию)
- Speech-to-Speech (переозвучка своей записи)
- Dubbing (перевод готового видео)
- «Оживить персонажа» (act_two / перформанс по видео-референсу) — только после того же согласия, что для фото
- Video-to-video / стиль (Aleph 2)
- Extend видео
- Upscale финального ролика
- Brand Kit (лого, водяной знак, цвета, CTA)
- Редактор сцен («пересоздать сцену N», остальные не трогать)
- История проектов
- Тарифы и лимиты кредитов на аккаунт
